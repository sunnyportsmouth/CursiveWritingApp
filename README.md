🖋️ CursiveTracingApp
CursiveTracingApp is a calming, educational iOS app that helps users (kids or adults) practice cursive writing. Designed using SwiftUI, the app offers letter and word tracing, font customization, and a relaxing user experience that feels like handwriting in a notebook.

✨ Features
🎨 Font Picker – Choose from cursive fonts like Snell Roundhand, Zapfino, and Copperplate

🔤 Alphabet Tracing – Practice uppercase A–Z with notebook-style lines

📖 Word Tracing – Trace randomly generated everyday words

🖊️ Freeform Drawing – Real-time finger tracing on-screen with red/blue strokes

🔄 Next / Clear Buttons – Easily reset or move to the next letter or word

🎵 (Optional) Calming Background Music – Supports ambient music for focus (add calm.mp3)
